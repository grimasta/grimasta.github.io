About

I am a software developer working on developer tooling, code intelligence, and data infrastructure. I recently finished my PhD in Computer Science at Western University, where I designed and built large-scale software analytics platforms in collaboration with the Cloud org at IBM (via IBM Research).

My research systems include SWEF, evaluated on more than 500,000 commits across 205 open-source projects, and CompleteExtractor, a fault-tolerant distributed pipeline for extracting source code metrics at scale. My work received the CASCON 2021 Best Paper Award. I work mostly in Java and Python, and I am based in London, Ontario, Canada.

Projects

SWEF

In-memory software evolution framework for mining and analyzing large software histories. Evaluated on 500,000+ commits across 205 projects.

CompleteExtractor

Fault-tolerant distributed pipeline for metric extraction. Provisions and orchestrates its own toolchains in isolated VMs and runs for months unattended.

MultiExtractor

Java toolkit for mining software repositories: source-code metrics, process metrics, and issue-tracker data, in a form ready for downstream analysis.

EasyTrader

Automated trading strategy tester with backtesting and paper trading. Built as a learning tool: it will teach you how trading works, not make you rich.

rosetta

Integrated software analytics and insights tool: point it at a git URL and get language-aware source metrics from the command line.
